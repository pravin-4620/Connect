## 🎨 Color Scheme

### Primary Colors
- **Gray-900** (#111827) - Headers, active states, buttons
- **Gray-50** (#F9FAFB) - Background, cards
- **Gray-100** (#F3F4F6) - Hover states, badges
- **White** (#FFFFFF) - Main content areas

### Accent Colors
- **Blue-50** (#EFF6FF) - Unread email background
- **Yellow-500** (#EAB308) - Star/important marker
- **Gray-200** (#E5E7EB) - Borders

### Text Colors
- **Gray-900** - Headings, bold text
- **Gray-700** - Body text, labels
- **Gray-600** - Secondary text
- **Gray-500** - Metadata (time, counts)

### Desktop (1024px+)

- Split view for email detail

- Collapsible sidebar

- Hidden sidebar (menu button)

## 🎭 User Flows

### Flow 1: First Time Setup
1. Click "Mails" tab
2. See connection screen
3. Click "Connect Gmail Account"
4. Authenticate with Google
5. Emails fetched and categorized
6. View inbox

### Flow 2: Reading Emails
1. Select category or search
2. Click email in list
3. View full email
4. Reply/Forward/Mark as read
5. Return to inbox

### Flow 3: Managing Emails
1. Star important emails
2. Mark as read/unread
3. Filter by category
4. Search by keyword
5. Compose new email

## 🚀 Performance

### Optimizations
- Lazy loading email bodies
- Virtual scrolling for large lists
- Debounced search (300ms)
- Cached category counts
- Memoized filter results

### Load Times
- Initial render: < 100ms
- Email fetch: 1-2s
- AI categorization: 2-3s
- Search: instant (client-side)
